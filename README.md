# MSLE — Materials Science Laboratory Equipment Ontology

MSLE describes materials science laboratory equipment.

## Ontology files

| File | Serialization | Ontology version metadata |
| --- | --- | --- |
| [MSLE.owl](MSLE.owl) | RDF Turtle | 1.1 |
| [MSLE0.1.owl](MSLE0.1.owl) | RDF Turtle | Not declared |
| [MSLE_Ver2.owl](MSLE_Ver2.owl) | OWL/XML | Not declared |

For terminology-service ingestion of version 1.1, use
[the raw MSLE.owl file](https://raw.githubusercontent.com/MehrdadJalali-AI/MSLE-Ontology/main/MSLE.owl).
Despite its `.owl` extension, this file uses Turtle syntax.
